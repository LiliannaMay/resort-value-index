# Resort Value Index

## Project Goal

Determine which all-inclusive resorts provide the best overall value.

## Tools

- Python
- Pandas
- Matplotlib

## Questions

- Which resort offers the best value?
- Does price correlate with ratings?
- Which amenities matter most?

## Results

Food quality had a stronger relationship with ratings than room size.
